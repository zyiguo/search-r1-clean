# GRPO 多问题组与有界补采样

目标：保留旧配置的单组行为，显式开启新采样策略，不修改奖励定义。

1. 新增 CPU 可测采样器：问题不放回抽样，每题独立标准化；目标 4 个有效组，最多 16 次尝试；不足时部分更新，零有效组跳过优化器和调度器。
2. 训练集成：有效轨迹总数归一化，过滤组不做 KL；记录全部组与成本、有效比例和是否更新；检查点轮数表示有界采样轮，包含跳过轮。
3. 配置/身份：新 GRPO 专属字段允许 SFT warm start，恢复仍精确匹配；使用独立输出路径。默认不启用过滤。
4. 测试：先失败后实现，覆盖全对/全错、问题内优势、部分收集、耗尽、预算、确定性、损失归一化；运行全套 CPU 测试。
5. 交付：文档明确新策略采样偏差与成本；云端从已有 3 epochs 配置生成新配置，禁止伪造本地未知 SFT 步数。

真实 GPU 吞吐、显存、恢复与效果需要云端验证。
