# SFT 300条完整轨迹：规则补齐版

沿用原HotpotQA规则：支持文档标题作为搜索词，标准答案作为最终回答。优先保留原合格教师轨迹，再从search/hotpot-grpo-2000训练问题补齐到300条。默认最多3次搜索，随后回答；不会给两次搜索的题目强加第三次搜索。候选支持文档数量必须为1至3。实际HotpotQA问题通常只有两篇支持文档，允许3次不代表自动产生大量三次搜索示例。

排除原val/test及固定eval-val300的val/test问题ID与规范化问题文本。候选数据身份必须与eval-val300记录的来源相符。原样复制eval-val300的corpus/val/test；在此语料上回放轨迹，检查合法动作、正确答案和全部支持文档命中。标题与答案使用训练标注；语义充分性及自主搜索推理未获验证。候选不足会报错，不重复凑数。

300条总量按问题分为270条训练、30条内部loss验证。3epoch，r32/alpha64，micro16/accumulation1，总上下文2048，动作上限512，最多搜索3次。学习率继承源SFT配置。按实际动作数计算步数，最终使用最优val loss adapter。检索回放不保证token长度合格，训练前仍执行原长度检查。

## 云端命令
```bash
cd /root/autodl-tmp/search-r1-clean
source /root/autodl-tmp/crosswoz-stage2/.venv/bin/activate
unzip -o sft300-patch.zip
export POSTTRAIN_ALLOW_CLOUD=1
python scripts/prepare_sft300.py
python -u scripts/train_compact.py sft --config search/sft-t300-r32-e3-b16-ctx2048.json
python -u search_train.py eval --config search/sft-t300-r32-e3-b16-ctx2048.json --variant B1 --eval-batch-size 64 --output "reports/search/B1-sft-t300-val300-$(date +%Y%m%d-%H%M%S).json"
```

默认源配置search/sft-r32-e3-b16-ctx2048.json；原轨迹search/hotpot-pilot；候选search/hotpot-grpo-2000；固定评测search/eval-val300。新数据search/sft-trajectories300，新模型outputs/search-sft-t300-r32-e3-b16-ctx2048。准备脚本会打印原始数量、保留数量、新增数量、内部划分和步数。已有输出会拒绝覆盖；可用--output和--destination指定新的数据/配置路径，已训练的模型输出另需新实验命名。

补丁覆盖当前项目中的准备入口，不另建项目，不修改根目录训练代码，保留旧检查点代码身份。新配置训练身份不同，不用于续训旧GRPO。新SFT评测使用search_train.py，不使用旧GRPO身份专用eval_validation300.py。旧严格比较器可能因训练身份不同拒绝比较，应核对相同评测题目与corpus哈希后进行配对分析。

本地仅CPU合成数据测试（包含三次搜索后回答），真实300条生成、token长度检查和GPU训练需云端执行。
