# 300题验证集

此补丁只增加独立评测入口，不修改训练代码、配置或原数据。保留原50题并新增250题，排除原训练/验证/测试的问题ID及规范化问题文本。使用2000题GRPO数据作为排除来源。新增题的上下文进入共享检索语料，因此SFT与GRPO都需重测，不能与旧语料的50题分数直接比较。原50题已经用于选择检查点，应重点关注新增250题表现。

上传 validation300-patch.zip 到云端项目目录后执行：

```bash
cd /root/autodl-tmp/search-r1-clean
source /root/autodl-tmp/crosswoz-stage2/.venv/bin/activate
unzip -o validation300-patch.zip
export POSTTRAIN_ALLOW_CLOUD=1
python scripts/prepare_validation300.py
STAMP=$(date +%Y%m%d-%H%M%S)
CONFIG=search/grpo-r32-e3-p48-g5-ctx2048.json
python -u scripts/eval_validation300.py --config "$CONFIG" --variant B1 --output "reports/search/B1-val300-$STAMP.json"
python -u scripts/eval_validation300.py --config "$CONFIG" --variant B3 --checkpoint-step 15 --output "reports/search/B3-step15-val300-$STAMP.json"
```

生成器默认读取 search/hotpot-grpo-2000 和 search/raw-recovery/hotpotqa-hf/distractor 下的两个train parquet分片，写入 search/eval-val300。需要环境已安装pyarrow。已有目录时拒绝覆盖；成功生成后再次评测可跳过生成命令。配置必须使用训练该检查点时的原配置；若云端文件名不同，请替换CONFIG。B3会验证检查点哈希和完整训练身份，不跳过校验。

其他检查点可将 --checkpoint-step 15 改为5或10，并使用不同输出文件名。报告包含总体EM与subsets.original/subsets.new各自题数及EM，保存独立评测数据身份和原训练身份。可继续使用项目search_compare.py比较同一新验证集上的报告。

本地只验证合成数据和CPU测试，没有下载真实数据或运行云端GPU评测。300题必须在云端执行生成后才实际生效。不要修改训练配置data_dir/grpo_data_dir来指向此评测专用数据。
